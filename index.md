# fakan

Vývojář ze středočeské vesnice. Stavím věci tak, aby šlapaly i za pět let bez aktualizace 47 NPM balíčků.

## stack

Serverless. Cloudflare od A do Z — Workers, D1, KV, R2, Durable Objects, Queues. Mobil přes Capacitor. Frontend píšu v pure JS a CSS. Bez frameworku, bez build stepu, bez `node_modules` o velikosti dokumentárního filmu.

Vue, React, Next? Když platí, postavím to. Nečekej u toho ale nadšení.

## co stavím

- **[kanban.fakan.cz](https://kanban.fakan.cz)** — kanban s magic link auth, fractional indexing kartiček, přílohy v R2
- **PlotGuard** — virtuální plot pro hospodářská zvířata. Bez měsíčního předplatného, na rozdíl od konkurence
- **AI email agenti** — pět specializovaných agentů orchestrovaných přes Cloudflare Email Routing + Workers + Claude API
- **CRM/ATS pro personálku** — devět modulů, 80+ tasků, napojení na ARES
- pár dalších věcí, které radši nelinkuju

## jak pracuju

Vedu malý tým. Děláme to tak, že to funguje, je to levné na provoz a nejde to za půl roku do koše kvůli upgrade hellu. Nepotřebuju Kubernetes ani microservices, abych ti udělal web pro firmu o pěti lidech.

GDPR-friendly bez 47 cookie banner pluginů. Cloudflare Web Analytics místo GA. Domain provisioning přes API. Recurring revenue místo dvacáté redesignové zakázky.
