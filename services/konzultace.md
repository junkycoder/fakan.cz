# Konzultace

Krátké rozhovory, druhý názor, code review. Hodina–dvě, řešíme konkrétní
problém. Nepotřebuju dlouhý onboarding.

## Kdy se hodím

- Stojíš nad volbou architektury (Rails, Vue, Workers) a chceš druhý
  pohled.
- Máš code review, na kterou nikdo z týmu nemá kapacitu.
- Chceš si projít konkrétní část kódu a vědět, co s ní.
- Plánuješ refactor a chceš ho rozdělit do iterací, které nerozbijou prod.

## Jak to probíhá

1. Napíšeš mi přes [e-mail](../contacts/email.md), co řešíš (3 věty stačí).
2. Domluvíme si hodinu, ideálně do týdne.
3. Hovor nebo video, případně async přes git/dokument.
4. Faktura po skončení.

Sazba a podrobnosti v [ceníku](cenik.md).
